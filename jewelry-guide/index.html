飾品體檢隨身小抄・一分鐘看懂鋼印

金飾、K金、白金、銀飾印記怎麼看？

拿起手邊的戒指、項鍊扣環或手鍊，不用背艱深術語——只要記住「先認開頭英文字、再看數字移一位小數點」，就能秒懂它是什麼材質、含多少純貴金屬。

一、手上飾品寫什麼？點一下直接翻譯

點選下方常見鋼印，或直接輸入你飾品內圈看到的英文字與數字：

黃金

9999 / Au9999（萬足純金）

純貴金屬比例 99.99%

二、這輩子只記這 2 招，九成鋼印都看懂

飾品上的小字其實只有兩部分：「英文字＝誰的家」、「數字＝純度幾分」。

第 1 招｜認開頭英文字

先分清它是哪一種金屬

  • 看到 Au、G、K ＝ 黃金家族（純金或 K 金）
  • 看到 Pt ＝ 真白金（鉑金），天然雪白不變黃
  • 看到 S、Ag ＝ 純銀（S 就是 Silver 銀）
  • 後面多出 GP 或 GF ＝ 只有表皮是金（電鍍或包金）
第 2 招｜數字變百分比

三位數往前推一位就是純度％

國際通用的三位數（千分比），只要在十位數與個位數中間點個小數點，就是幾％純度：

  • 999 → 99.9%（純到幾乎滿分）
  • 950 → 95.0%（鉑金主流：95% 鉑金）
  • 925 → 92.5%（標準純銀：92.5% 銀）
  • 750 → 75.0%（就是 18K 金）
  • 585 → 58.5%（就是 14K 金）
補充小常識｜K 數怎麼算

把純金切成「24 等分」

歐美和台灣很常講「幾 K」，其實就是把滿分當成 24 塊蛋糕：

  • 24K ＝ 24 塊全純金（100% 純金概念）
  • 18K ＝ 佔 18 塊（18÷24 ＝ 75% ＝ 750）
  • 14K ＝ 佔 14 塊（14÷24 ＝ 58.5% ＝ 585）
  • 10K ＝ 佔 10 塊（10÷24 ＝ 41.7% ＝ 417）

三、四大類飾品常用號碼對照

為什麼有的寫英文、有的只寫數字？其實它們說的是同一件事，只是各國習慣不同。

1. 黃金（純金）

代表字母：Au / 足金
9999 / Au9999 99.99% 純金（四九金）
999 / Au999 / 24K 99.9% 純金（千足金）
990 / Au990 99.0% 純金（傳統工藝常見）
916 / 22K 91.6% 金（東南亞／古法硬金常見）

2. K 金（黃金混其他金屬）

代表字母：K / Au / G
18K / 750 / Au750 / K18 75% 黃金（高級鑽戒最常用）
14K / 585 / Au585 58.5% 黃金（耐磨耐戴日常款）
10K / 417 / Au417 41.7% 黃金（日系輕珠寶常見）
9K / 375 / Au375 37.5% 黃金（英國與古董飾品常見）

3. 白金（正式名稱：鉑金）

代表字母：Pt / PLAT
Pt999 / Pt990 99% 以上純鉑金（偏軟、多為素圈）
Pt950 95% 鉑金（國際鑽戒戒台標準）
Pt900 90% 鉑金（日本經典婚戒、抓鑽牢）
Pt850 85% 鉑金（日本項鍊鍊條／扣頭常用）

4. 銀飾

代表字母：S / Ag / Sterling
S999 / Ag999 / 足銀 99.9% 純銀（軟，常見於手鐲）
S950 / Ag950 95% 純銀（日系職人手作常見）
S925 / 925 / STERLING 92.5% 純銀（加入 7.5% 銅增加硬度）
800 / 835 80%～83.5% 銀（歐洲老件古董銀器）

四、大家最常看錯的 4 個地方

逛銀樓、買精品或整理舊首飾時，只要避開這四個誤會就不會買錯、也不會洗壞飾品。

誤會 1：「白金」跟「白 K 金」是不一樣的東西！

• 真白金（印 Pt950、Pt900）：本身就是銀白色的鉑金，怎麼磨都還是白的，拿起來比較沉。

• 白 K 金（印 18K WG、750）：裡面其實是「黃澄澄的 75% 黃金」，只是外面鍍了一層亮白色；戴久磨損會微微變淡黃，拿去重鍍就恢復雪白。

誤會 2：看到「750」沒寫 K，跟「18K」一樣嗎？

完全一樣！只是寫法習慣不同：

• 美國與台灣口語愛寫 18K（18÷24 ＝ 75%）。

• 歐洲精品（如百貨常見一線品牌）習慣直接印千分比 750 或 Au750。

• 若看到 K 寫在前面（例如 K18、K10），幾乎都是日本設計／日本製造的標示法。

誤會 3：只看數字不看英文字，會把銀看成金！

因為千分比大家都在用，數字一樣，金屬可能完全不同：

• Au999 是純黃金，但 S999 是純銀。

• Pt950 是白金（鉑金），但 Ag950 是高純度銀。

所以讀印記時，一定要把前面的英文字跟後面數字一起看。

誤會 4：看到 18K GP / 14K GF 以為是純 K 金

只要印記尾巴出現 P 或 F，就不是整件實心貴金屬：

• GP / GEP ＝ 電鍍金（表面噴鍍超薄一層金）。

• GF / RGP ＝ 包金（外面包一層較厚的 K 金皮，裡面是銅）。

• VERMEIL 925 ＝ 925 純銀外層厚鍍黃金。清潔時不可用力刷或過度拋光，以免磨掉外層。
